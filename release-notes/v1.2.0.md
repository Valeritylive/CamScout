Приложение переименовано в **CamScout** и теперь доступно в формате Flatpak.

### Что нового

**Новое название: CamScout**
- Hikvision Device Manager теперь называется CamScout. Это независимый проект, не связанный с производителями камер; новое имя без чужого товарного знака нужно для публикации в Flathub.
- Команда запуска теперь `camscout`. В пакете `.deb` старая команда `hikvision-device-manager` продолжает работать, а новый пакет `camscout` автоматически заменяет старый.
- Новая иконка, идентификатор приложения `io.github.Valeritylive.CamScout`.
- Код опубликован под лицензией MIT.

**Flatpak**
- В релиз добавлен файл `CamScout-x86_64.flatpak`. Он работает в любом дистрибутиве с Flatpak, рантайм GNOME подтягивается из Flathub автоматически.
- Приложение получает только доступ к сети и экрану; файлы выбираются через системный диалог.
- Сборка Flatpak и проверка `flatpak-builder-lint` выполняются при каждом изменении.

### Установка Flatpak

```bash
flatpak install --user ./CamScout-x86_64.flatpak
flatpak run io.github.Valeritylive.CamScout
```

### Установка на Debian/Ubuntu amd64

```bash
sudo apt install ./camscout_1.2.0-1_amd64.deb
```

### AppImage

```bash
chmod +x CamScout-x86_64.AppImage
./CamScout-x86_64.AppImage
```
