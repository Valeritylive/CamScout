Исправлен запуск пакетов `.deb` и AppImage.

### Исправлено

- Программа из `.deb` и AppImage падала при запуске с ошибками `Fontconfig error: Cannot load default config file` и `xkbcommon: Couldn't find file "rules/evdev"` (особенно в сеансе Wayland). Встроенные библиотеки искали шрифты, раскладки клавиатуры и загрузчики иконок по пути сборочной машины. Теперь общий скрипт запуска `run.sh` направляет их во встроенное окружение программы, а шрифты берёт из системы.
- Просмотр видео использует только встроенные модули GStreamer.

### Установка на Debian/Ubuntu amd64

```bash
sudo apt install ./camscout_2.0.1-1_amd64.deb
```

### AppImage

```bash
chmod +x CamScout-x86_64.AppImage && ./CamScout-x86_64.AppImage
```

### Flatpak

```bash
flatpak install --user ./CamScout-x86_64.flatpak
```
