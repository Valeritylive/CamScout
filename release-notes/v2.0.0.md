CamScout 2.0 объединяет Dahua Device Manager и CamScout (бывший Hikvision Device Manager) в одну программу.

### Что нового

- Устройства Dahua и Hikvision в одном списке, у каждого метка бренда. Есть фильтр по бренду, а в настройках поиска любой бренд можно выключить.
- Интерфейс по образцу Dahua ConfigTool: разделы «Устройства», «Настройки устройства», «Прошивка», «Сброс пароля», «Журнал», «Параметры».
- Активация, смена IP (в том числе пакетная), просмотр видео и сброс пароля работают для обоих брендов.
- Выбор языка в «Параметрах»: English (по умолчанию), русский, Deutsch, Español, Հայերեն.
- Новый салатово-зелёный акцент и иконка.
- Командная строка: `camscout dahua …` и `camscout hikvision …`.
- Пакет `.deb` заменяет `hikvision-device-manager` и `dahua-device-manager`; старые команды остаются ссылками на `camscout`.

### Установка

```bash
flatpak install --user ./CamScout-x86_64.flatpak
sudo apt install ./camscout_2.0.0-1_amd64.deb
chmod +x CamScout-x86_64.AppImage && ./CamScout-x86_64.AppImage
```
